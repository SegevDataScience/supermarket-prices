# השוואת סל קניות
1. התקינו Python 3 ו-Claude Code והתחברו. לחיצה כפולה על `start.bat` מפעילה שרת מקומי (127.0.0.1 בלבד) ופותחת דפדפן; החלון נשאר פתוח ומאתחל את השרת אם הוא נופל.
2. "מה קונים?": טקסט חופשי, או בניית רשימה (מוצר, כמות, יחידה) עם שמירת רשימות בשם (`lists.json`).
3. "איפה?": כתובת ורדיוס 2-25 ק"מ (הרחבה אוטומטית ל-8/15/25 אם יש פחות מ-3 סניפים), או בחירת ערים קרובות.
4. ההשוואה נעשית על ידי התוסף `il-supermarket-compare` (עותק קפוא ב-`vendor`), דרך Claude Code עם הרשאות מוגבלות.
5. חיפוש ראשון באזור או בעיר חדשים יכול לקחת 20-30 דקות (איתור כתובות); אחר כך דקות ספורות. כפתור "עצור" מפסיק את כל התהליכים.
6. מחירי מדף מהקבצים היומיים בלבד: בלי מבצעים ומחירי מועדון. המרחקים בקו אווירי. התאריך המוצג הוא תאריך הורדת קובץ המחירים.
7. לא מכוסות: ויקטורי, חצי חינם, מחסני השוק, יינות ביתן. רשת שלא פרסמה קובץ היום מדולגת ומצוינת בתוצאה.
8. מטמון משותף: `~/.cache/il-supermarkets`. יומן לכל חיפוש: `.il-supermarket-work/job-*.log`. היסטוריה: `history.json`.
9. אם חסרה ספריית requests: `python -m pip install requests`.
